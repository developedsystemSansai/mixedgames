# Let me ทาย

เกมปาร์ตี้ทายคำบนเว็บ เล่นพร้อมกัน 2–10 คน แต่ละคนใช้มือถือของตัวเอง ไม่ต้องสมัครสมาชิก

- **อะไรอยู่หัวกู** เห็นคำของเพื่อนทุกคนยกเว้นของตัวเอง ถามใช่/ไม่ใช่แล้วพิมพ์ทาย คนทายถูกก่อนได้ 3/2/1 แต้ม
- **คำต้องห้าม** ทุกคนมีคำที่ห้ามพูด ใครเผลอพูดโดนเพื่อนกด "จับได้!" แล้วโหวตเสียงข้างมาก รอดจนจบรอบได้ 1 แต้ม (คนสุดท้ายได้ 2) คนจับถูกได้ 1 แต้ม

## ฟีเจอร์
- **ตั้งเวลาทายได้สูงสุด 30 นาที** (ไม่จำกัด / 3 / 5 / 10 / 15 / 20 / 30) มีแถบเวลาและเสียงนับถอยหลัง 10 วินาทีสุดท้าย
- **สมุดจดคำใบ้** ปุ่มมุมขวาล่างระหว่างเล่น จดคำใบ้ของเพื่อนแยกตามคน พร้อมแท็ก ใช่ / ไม่ใช่ / คำใบ้ / สงสัย
  เก็บในเครื่องของผู้เล่น (localStorage) แยกตามห้องและรอบ เป็นส่วนตัว ไม่ส่งขึ้นเซิร์ฟเวอร์ และล้างเองเมื่อขึ้นรอบใหม่
- **อนิเมชันและเอฟเฟกต์** แนะนำรอบ, ตั๋วคำพลิกเปิด, คอนเฟตติ/พลุตอนชนะ, จอแดงสั่นตอนโดนจับ, คะแนนนับขึ้น, แบนเนอร์แจ้งเหตุการณ์
  พร้อมเสียงสังเคราะห์ (ปุ่มลำโพงมุมขวาบน) และรองรับ `prefers-reduced-motion`

## โครงสร้าง
- `index.html`, `css/`, `js/` — หน้าเว็บล้วน (ไม่มี build step) โฮสต์บน GitHub Pages ได้เลย
- `js/fx.js` — คอนเฟตติ เสียง แฟลช แบนเนอร์ / `js/app.js` — UI และ logic ทั้งหมด
- `assets/game/` — มาสคอตและไอคอน (webp) · `assets/scene.webp` — ฉากหลังบนจอกว้าง · `assets/logo.webp` — โลโก้
- `tools/make_sign.py` — สร้างโลโก้ "Let me ทาย" และฝังลงฉากหลังจากภาพต้นฉบับ (ต้องมีฟอนต์ Fredoka + Mitr)
- `supabase/001_schema.sql` — ตาราง `mg_*` และฟังก์ชัน RPC ทั้งหมด (จำกัดเวลาสูงสุด 30 นาทีฝั่งเซิร์ฟเวอร์อยู่แล้ว)
- คลังคำอยู่ในตาราง `mg_words` (หมวด, ระดับ 1–5, คำ) เพิ่มคำได้ด้วย  
  `insert into mg_words(category, level, text) values ('หมวดใหม่', 3, 'คำใหม่');`

## ความปลอดภัยโดยย่อ
ทุกตารางเปิด RLS และไม่มี policy จึงอ่านตรงจากเว็บไม่ได้ ทุกการกระทำผ่าน RPC ที่ตรวจโทเคนผู้เล่น
เซิร์ฟเวอร์ไม่ส่ง "คำบนหัวของตัวเอง" ให้ฝั่งผู้เล่นเลย จึงแอบดูจาก DevTools ไม่ได้
ห้องที่ไม่มีความเคลื่อนไหวเกิน 1 วันจะถูกลบอัตโนมัติเมื่อมีคนสร้างห้องใหม่
